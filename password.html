ACCOUNT SECURITY

Password Security

Learn how to create stronger passwords and protect your online accounts.

SECURITY BASICS

Build Better Passwords

🔐

Use Long Passwords

Prefer longer passwords or passphrases that are difficult to guess.

🔄

Use Unique Passwords

Avoid using the same password across multiple important accounts.

📱

Enable MFA

Multi-factor authentication adds another layer of protection to your accounts.

🚫

Avoid Personal Information

Avoid easily guessed information such as names, birthdays and phone numbers.

BEST PRACTICES

Password Security Checklist
